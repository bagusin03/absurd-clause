One line, 191 characters: an absurd clause buried deep in a terms-of-service agreement — deadpan legal boilerplate until the sponsored advertisement waves back.

`main.ts` writes the single 191-character clause to `/output/entry.txt`:

> Section 11.6: the Company reserves the right, at its sole discretion, to replace the User's own reflection in any mirror with a sponsored advertisement, provided the advertisement waves back.

The joke lands on one reading with no setup: it opens as pure boilerplate ("reserves the right, at its sole discretion") and the absurdity is one concrete image — your own reflection swapped for an ad that waves back at you.

Offline and deterministic: no network, no clock, no randomness. A runtime guard enforces the 1–200 character single-line gate and verifies the written file round-trips exactly, byte for byte.

Run it with Node 22+:

```
node main.ts
```
